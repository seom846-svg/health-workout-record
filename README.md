헬스 운동 기록 프로그램

1. 프로그램 소개

이 프로그램은 사용자가 자신의 헬스 운동 기록을 간편하게 관리할 수 있도록 제작한 웹 프로그램입니다.

운동 종목, 세트 수, 반복 횟수 등을 입력하여 운동 기록을 저장하고 전체 운동량을 확인할 수 있습니다.

2. 주요 기능

운동 기록 추가 기능

운동 세트 및 반복 횟수 입력

전체 운동량 확인

저장된 운동 기록 삭제

입력값 검증 기능

3. 사용 방법

웹사이트에 접속합니다.

운동 종목을 입력합니다.

세트 수와 반복 횟수를 입력합니다.

추가 버튼을 눌러 운동 기록을 등록합니다.

등록된 운동 기록과 전체 운동량을 확인합니다.

필요하지 않은 기록은 삭제할 수 있습니다.

4. 제작 목적

일상적인 헬스 운동 기록을 편리하게 관리하고, 웹 프로그래밍을 통해 실제로 사용할 수 있는 프로그램을 구현하는 것을 목적으로 제작하였습니다.
